# UI management and configuration verification — 2026-09-15

## User-facing changes

- All primary subpages now use the selected language, including Overview, Configuration, Installed, Discover, Updates, Activity, controls, empty states, and status messages.
- The Homebrew-style toolbar has a persistent sidebar collapse button. The choice is stored locally and the collapsed state keeps icon navigation available.
- Configuration reads the parsed `.zshrc` values and renders the current theme plus recognized plugins as checkboxes. Preview still routes through the existing syntax-check, backup, stale-source, and atomic-apply path.
- Installed and Discover rows use repository/fallback icons, descriptions, star counts, update dates, installed badges, and direct GitHub repository links.
- Updates no longer presents an unexplained initial `0`: it shows an em dash before the first check, starts a real check when the Updates page opens, and reports the result in the status bar.
- Activity now lists configuration backups with Restore and Delete actions. Backend path validation restricts both operations to `.ohmyzsh-gui/backups/*.zshrc`; restoring creates a new safety backup and records the operation.
